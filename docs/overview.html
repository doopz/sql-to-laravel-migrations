sql-to-laravel-migrations

A script that generates Laravel migrations from an existing MySQL database. Not exhaustive: it's meant to speed up adopting migrations on a legacy schema, which you then review by hand.

Key features

🗃️

Schema to migrations

Reads tables and columns from MySQL and writes one migration per table.

🔢

Type mapping

Maps MySQL column types to Laravel schema builder methods, incl. nullable.

📇

Indexes

Generates index definitions.

💬

Comments

Carries column comments into the migration.

🎚️

Table filters

only_include_tables or exclude_tables in config.json.

🐞

Debug mode

Optional debug output while converting.
